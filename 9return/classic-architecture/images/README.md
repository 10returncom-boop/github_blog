# 圖片資源目錄

## 命名規範

建議按照以下規則命名圖片，方便管理與維護：

### 首頁相關
- `banner.jpg` - 首頁大橫幅 (建議尺寸: 1920x800)
- `about.jpg` - 關於區塊圖片 (建議尺寸: 800x500)
- `card-01.jpg` ~ `card-06.jpg` - 專欄/服務卡片圖 (建議尺寸: 600x400)

### Blog 相關
- `blog-01.jpg` ~ `blog-06.jpg` - 文章列表縮圖 (建議尺寸: 600x400)
- `blog-cover.jpg` - 文章封面圖 (建議尺寸: 1200x675)
- `related-01.jpg` ~ `related-03.jpg` - 相關文章縮圖
- `author.jpg` - 作者頭像 (建議尺寸: 200x200)

### 商品相關
- `product-01.jpg` ~ `product-08.jpg` - 商品列表圖 (建議尺寸: 600x600)
- `product-main.jpg` - 商品主圖 (建議尺寸: 800x800)
- `product-thumb-01.jpg` ~ `product-thumb-04.jpg` - 商品縮圖
- `related-p-01.jpg` ~ `related-p-04.jpg` - 相關商品圖

### 關於頁相關
- `about-hero.jpg` - 關於頁主圖
- `team-01.jpg` ~ `team-03.jpg` - 團隊成員照片

## 格式建議
- 優先使用 WebP 格式（體積小、畫質好）
- 其次使用 JPG（照片類）或 PNG（有透明背景）
- 所有圖片建議壓縮後再上傳
