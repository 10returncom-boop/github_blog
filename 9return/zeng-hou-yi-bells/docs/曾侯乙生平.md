# 曾侯乙生平與戰國曾國歷史

## 曾侯乙是誰

### 身份確定

曾侯乙，姬姓，曾氏，名乙，是戰國早期曾國（又稱隨國）的君主。其身份的確定主要依據：

1. **青銅器銘文**：墓中出土的大量青銅禮器上鑄有「曾侯乙作持」「曾侯乙之用」等銘文
2. **鎛鐘銘文**：下層正中的一件鎛鐘上銘刻「楚王酓章作為曾侯乙宗彝」，明確指出墓主人為曾侯乙
3. **墓葬規格**：墓葬形制、隨葬品數量和質量均符合諸侯等級

### 在位年代

根據墓中出土器物的風格和銘文紀年，曾侯乙的下葬年代約為公元前433年（楚惠王五十六年）。其在位時間大約在公元前450年至公元前433年之間。

鎛鐘銘文「惟王五十又六祀」，指楚惠王五十六年，即公元前433年。楚惠王專門為曾侯乙鑄造了這件鎛鐘，作為祭祀用的禮器，說明曾楚兩國關係極為密切。

### 年齡推測

根據對墓主人骨架的鑑定，曾侯乙去世時年齡約在42-45歲之間，身高約1.62米。

## 曾國（隨國）歷史

### 曾隨之謎

曾國，即文獻中的隨國，是周代漢東地區的一個重要姬姓諸侯國。

- **文獻稱「隨」**：《左傳》《史記》等古籍中稱為「隨國」
- **銅器稱「曾」**：出土青銅器銘文中自稱「曾」
- **曾隨一國**：學術界經過長期討論，現已確認「曾」即「隨」，是同一個國家的兩種稱謂

曾國是周王朝鎮守南方的重要諸侯國，地處漢水以東，故稱「漢東之國隨為大」。

### 地理位置

曾國的統治中心在今湖北省隨州市一帶：
- 都城「西陽」：在今隨州境內
- 統治範圍：以隨州為中心，包括棗陽、安陸等地
- 戰略位置：地處漢水以東，是周王朝與楚國之間的緩衝地帶

### 歷史沿革

| 時期 | 事件 |
|------|------|
| 西周早期 | 周成王分封，曾國建立，鎮守漢東 |
| 西周晚期 | 曾國強盛，「漢東之國隨為大」 |
| 春秋早期 | 楚國崛起，曾楚之間戰爭不斷 |
| 公元前706年 | 楚武王伐隨，隨國戰敗但未亡 |
| 公元前690年 | 楚武王再次伐隨，死於軍中，隨國求和 |
| 春秋中晚期 | 隨國淪為楚國附庸，但保持獨立 |
| 戰國早期 | 曾侯乙在位，曾楚關係密切 |
| 戰國中期 | 曾國最終被楚國吞併 |

### 曾楚關係

曾國與楚國的關係經歷了從對抗到臣服的演變：

1. **西周至春秋早期**：曾國作為周王朝的「南國之鎮」，與楚國對抗
2. **春秋中期**：楚國強大，曾國淪為附庸，但在楚國的保護下保持了相當的自主性
3. **春秋晚期**：楚國發生「柏舉之戰」，吳國攻入楚都，楚昭王逃到隨國避難，隨國保護了楚昭王，曾楚關係進入蜜月期
4. **戰國早期**：曾侯乙時期，曾楚關係極為密切，楚惠王專門為曾侯乙鑄造鎛鐘

楚惠王是楚昭王之子，當年隨國保護了楚昭王，楚惠王即位後對曾國優待有加，這也是為什麼楚惠王會專門為曾侯乙鑄造祭祀禮器的原因。

## 曾侯乙墓

### 墓葬形制

曾侯乙墓位於湖北省隨州市城西的擂鼓墩，是一座大型豎穴土坑木槨墓：

- **墓坑面積**：約220平方米
- **墓坑深度**：約13米
- **槨室結構**：用巨大的梓木構築，分為東、北、中、西四個室
- **填土**：經過夯築，堅硬密實

墓坑面積比馬王堆一號墓大6倍，比出土越王勾踐劍的望山一號楚墓大8倍。

### 槨室佈局

| 室名 | 位置 | 功能 | 主要文物 |
|------|------|------|----------|
| 東室 | 東側 | 墓主人寢室 | 曾侯乙主棺、8具陪葬棺、大量玉器、金器、兵器 |
| 中室 | 中央 | 禮樂廳 | 全套編鐘、編磬、青銅禮器、各種樂器 |
| 北室 | 北側 | 兵器庫與藏書室 | 大量兵器、車馬器、竹簡（文書） |
| 西室 | 西側 | 陪葬區 | 13具陪葬棺（年輕女性） |

### 陪葬者

墓中共有21具陪葬棺，均為年輕女性，年齡在13-25歲之間：
- 東室8具：可能是曾侯乙的妾媵或近侍
- 西室13具：可能是樂工或舞女

她們的遺骨保存較好，為研究當時的人種、健康狀況提供了珍貴資料。這種人殉制度在戰國早期已逐漸廢止，曾侯乙墓的人殉是這一制度的晚期遺留。

### 出土文物總覽

曾侯乙墓共出土各類文物15000餘件，是迄今為止出土文物最豐富的戰國墓葬之一：

- **青銅器**：總重量達10.5噸，包括禮器、樂器、兵器、車馬器等
- **玉器**：300餘件，質地優良，工藝精湛
- **金器**：5件，包括金盞、金杯、金帶鉤等，總重約7斤
- **漆器**：170餘件，色彩鮮豔，紋飾精美
- **竹簡**：240餘枚，記載了葬儀、車馬、兵器等信息
- **樂器**：8種125件，是迄今為止出土樂器最多的古代墓葬

## 曾侯乙的音樂世界

### 對音樂的重視

曾侯乙是一位酷愛音樂的諸侯，這從其墓葬的陳設可以明顯看出：

1. **中室作為禮樂廳**：墓葬中室完全按照宮廷禮樂場景佈置，編鐘、編磬、建鼓、瑟、笙等樂器排列有序
2. **大量樂器隨葬**：8種125件樂器，涵蓋了打擊、彈撥、吹奏三大類
3. **專業樂工陪葬**：21位陪葬女性中，有不少是樂工和舞女
4. **樂律銘文**：編鐘上的3755字銘文，是一部系統的樂律學著作

### 出土樂器一覽

| 樂器類型 | 數量 | 說明 |
|----------|------|------|
| 編鐘 | 65件 | 鈕鐘19、甬鐘45、鎛鐘1，音域五個半八度 |
| 編磬 | 32件 | 石質，分上下兩層懸掛，部分已殘損 |
| 建鼓 | 1件 | 大型打擊樂器，以青銅神獸為座 |
| 懸鼓 | 2件 | 小型鼓，用於節奏 |
| 扁鼓 | 1件 | |
| 瑟 | 12件 | 彈撥樂器，25弦 |
| 笙 | 5件 | 吹奏樂器，葫蘆製作 |
| 排簫 | 2件 | 13管排簫 |
| 篪 | 2件 | 橫吹竹管樂器 |
| 琴 | 1件 | 十弦琴，與後世七弦琴不同 |

這批樂器構成了一個完整的宮廷樂隊配置，可以演奏大型禮樂作品。

### 禮樂制度

曾侯乙墓的樂器配置嚴格遵循了周代的禮樂制度：

- **諸侯軒縣**：編鐘三面懸掛（軒縣），符合諸侯等級（天子四面「宮縣」，諸侯三面「軒縣」，卿大夫兩面「判縣」，士一面「特縣」）
- **樂舞佾數**：陪葬樂工的數量也符合諸侯等級
- **禮器組合**：青銅禮器的組合（九鼎八簋）也符合諸侯規格

這說明雖然曾國已淪為楚國附庸，但在禮樂制度上仍保持了周王朝的諸侯規格。

## 曾侯乙的其他身份

### 軍事統帥

墓中北室出土了大量兵器，包括戈、矛、戟、劍、箭鏃等，總數達4500餘件。這些兵器可能是曾侯乙軍隊的裝備，也可能是用於葬儀的明器。

其中最著名的是「曾侯乙之寢戈」，戈上銘有「曾侯乙之寢戈」字樣，是曾侯乙的專用兵器。

### 車馬愛好者

墓中出土了大量車馬器，包括車轄、車軎、馬鑣、馬銜等，總數1100餘件。北室竹簡中還記載了葬儀中使用的車馬數量，說明曾侯乙對車馬的重視。

### 玉器收藏者

墓中出土玉器300餘件，包括璧、環、璜、玦、佩、劍珌等，質地有和田玉、岫岩玉等，工藝極為精湛。這些玉器多數放置在曾侯乙的屍身周圍，是其生前喜愛之物。

其中最著名的是「十六節龍鳳玉佩」，由五塊玉料雕成，以活環相連，可以摺疊，是戰國玉器的巔峰之作。

## 歷史評價

曾侯乙雖然在政治軍事上並非顯赫一時的君主，但其墓葬中出土的文物，尤其是編鐘，使其成為中國古代音樂史上最重要的人物之一。

他的墓葬為後人留下了：
- 世界上現存最古老、最完整的青銅編鐘
- 公元前五世紀世界上最先進的樂律學體系
- 戰國早期最豐富的墓葬文物收藏
- 研究先秦禮樂制度、青銅工藝、音樂文化的第一手資料

曾侯乙或許沒有想到，他死後兩千四百多年，他的編鐘會「一醒驚寰宇」，成為中華民族文化的象徵，讓全世界為之驚嘆。
