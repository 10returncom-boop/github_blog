# 曾侯乙編鐘樂律體系

## 五聲音階

### 宮商角徵羽

中國傳統音樂的基礎是五聲音階，稱為「五音」：

| 音名 | 唱名 | 對應西音 | 頻率比（三分損益） | 頻率（以宮=C4=261.63Hz） |
|------|------|----------|---------------------|---------------------------|
| 宮 | do | C | 1/1 | 261.63 Hz |
| 商 | re | D | 9/8 | 293.66 Hz |
| 角 | mi | E | 81/64 | 329.63 Hz |
| 徵 | sol | G | 3/2 | 392.00 Hz |
| 羽 | la | A | 27/16 | 440.00 Hz |

五音的排列順序為：宮-商-角-徵-羽，對應 do-re-mi-sol-la，沒有半音（fa和si），因此音樂風格純樸、和諧，沒有強烈的傾向性。

### 五音的文化意涵

古人將五音與社會倫理、自然萬物相聯繫：

- **宮為君**：宮音是五音之主，如同君主統治天下
- **商為臣**：商音輔佐宮音，如同臣子輔佐君主
- **角為民**：角音代表百姓，是社會的基礎
- **徵為事**：徵音代表事務、活動
- **羽為物**：羽音代表萬物、物質

《管子·地員篇》記載了五音的生成方法，《呂氏春秋·音律》則系統闡述了十二律的相生關係。

## 三分損益法

### 生律原理

三分損益法是中國古代最基本的生律方法，記載於《管子·地員篇》。其原理是：

將一根弦的長度分為三份：
- **損一**（三分損一）：去其一份，剩三分之二，弦長變短，音高升高五度
- **益一**（三分益一）：增其一份，變為三分之四，弦長變長，音高降低四度

### 五音生成過程

以「宮」音的弦長為81作為基準：

```
宮 = 81                          （基準，do）
81 × 4/3 = 108 → 徵（益一，升高四度，實際為下方四度，sol）
108 × 2/3 = 72  → 商（損一，升高五度，re）
72  × 4/3 = 96  → 羽（益一，升高四度，la）
96  × 2/3 = 64  → 角（損一，升高五度，mi）
```

生成順序為：宮 → 徵 → 商 → 羽 → 角

按音高排列為：宮(81) → 商(72) → 角(64) → 徵(108移低八度=54) → 羽(96移低八度=48)

### 頻率比與音分

| 音名 | 弦長比 | 頻率比 | 與十二平均律差異（音分） |
|------|--------|--------|--------------------------|
| 宮 | 1/1 | 1.000 | 0 |
| 商 | 8/9 | 1.125 | +3.9 |
| 角 | 64/81 | 1.266 | +7.7 |
| 徵 | 2/3 | 1.500 | +2.0 |
| 羽 | 16/27 | 1.688 | +5.9 |

三分損益法生成的五音是純粹的自然諧音關係，聽感更和諧純淨；十二平均律將八度均分為十二份，方便轉調但每個音都略有偏差。

## 十二律

### 十二律名稱

十二律是中國古代的半音音階，每個律有專門的名稱：

| 序號 | 律名 | 別名 | 對應西音 | 月份 |
|------|------|------|----------|------|
| 1 | 黃鐘 | 太宮 | C | 十一月 |
| 2 | 大呂 | | C#/Db | 十二月 |
| 3 | 太簇 | 小呂 | D | 正月 |
| 4 | 夾鐘 | | D#/Eb | 二月 |
| 5 | 姑洗 | | E | 三月 |
| 6 | 中呂 | 小呂 | F | 四月 |
| 7 | 蕤賓 | | F#/Gb | 五月 |
| 8 | 林鐘 | 南呂 | G | 六月 |
| 9 | 夷則 | | G#/Ab | 七月 |
| 10 | 南呂 | | A | 八月 |
| 11 | 無射 | | A#/Bb | 九月 |
| 12 | 應鐘 | | B | 十月 |

十二律分為六陽律（黃鐘、太簇、姑洗、蕤賓、夷則、無射）和六陰呂（大呂、夾鐘、中呂、林鐘、南呂、應鐘），合稱「律呂」。

### 十二律相生

用三分損益法從黃鐘開始，依次生成十二律：

```
黃鐘 → 林鐘（損一）→ 太簇（益一）→ 南呂（損一）→ 姑洗（益一）
→ 應鐘（損一）→ 蕤賓（益一）→ 大呂（損一，需移高八度）
→ 夷則（益一）→ 夾鐘（損一，移高八度）→ 無射（益一）
→ 中呂（損一，移高八度）
```

這就是「隔八相生」法——從某律起數到第八個律，即為所生之律。

### 曾侯乙編鐘的十二律實踐

曾侯乙編鐘的出土，證明了中國十二律的實踐開始於周代：
- 中心音域約三個八度範圍內，十二個半音齊備
- 能夠旋宮轉調，演奏各種調式的樂曲
- 鐘銘文中記載了完整的十二律名稱和各國律制對照
- 音律綜合了三分損益律和純律的特點

這比西方巴赫時代（18世紀）十二平均律的系統實踐早了約兩千年。

## 七聲音階

### 五正聲與二變聲

曾侯乙編鐘不僅有五聲音階，還具備完整的七聲音階。七聲音階是在五聲音階的基礎上，加入兩個「變聲」：

| 音級 | 名稱 | 唱名 | 對應西音 | 說明 |
|------|------|------|----------|------|
| 1 | 宮 | do | C | 五正聲之一 |
| 2 | 商 | re | D | 五正聲之一 |
| 3 | 角 | mi | E | 五正聲之一 |
| 4 | 清角（變宮） | fa | F | 變聲之一 |
| 5 | 徵 | sol | G | 五正聲之一 |
| 6 | 羽 | la | A | 五正聲之一 |
| 7 | 變宮（閏） | si | B | 變聲之一 |

過去學術界認為先秦只有五聲音階，七聲音階是後來從西域傳入的。曾侯乙編鐘的出土推翻了這一觀點——銘文中明確出現了「變宮」一詞，證明中國在公元前五世紀已使用七聲音階。

### 音阶结构

全套鐘的音階結構與現代國際通用的C大調七聲音階屬同一音列。在中心音域內，十二個半音齊備，可以演奏五聲、六聲、七聲各種音階的樂曲。

## 旋宮轉調

### 概念

「旋宮轉調」是指以十二律中的任何一律作為宮音（主音），構成不同的調式。類似於西方音樂中的「轉調」。

- **旋宮**：改變宮音的高度，即以不同的律作為宮
- **轉調**：在同一宮音內改變調式（如宮調式、商調式等）

### 曾侯乙編鐘的旋宮能力

曾侯乙編鐘具備完整的旋宮轉調能力：
- 中心音域十二半音齊備，具備旋宮的物質基礎
- 銘文中記載了多種宮調名稱，如「黃鐘之宮」「姑洗之宮」等
- 可以演奏不同調式的樂曲，適應不同場合的需要

《戰國策》中記載的「引商刻羽，雜以流徵」，說明當時的音樂已運用複雜的轉調技巧。

## 各國律制對照

曾侯乙編鐘銘文中記載了當時各國（周、楚、曾、齊、晉、申等）的律名對照關係，這是研究先秦音樂地理的珍貴資料。

銘文顯示，不同國家的律名體系有所差異，但實際音高可以對應。這說明當時各國之間有著廣泛的音樂文化交流，曾侯乙編鐘作為曾國的禮器，其銘文承擔了「樂律對照手冊」的功能。

## 銘文中的樂律學

### 銘文內容分類

編鐘及鐘架上的3755字銘文，內容涉及樂律學的各個方面：

1. **階名**：宮、商、角、徵、羽等五正聲名稱
2. **變化音名**：宮角、商角、徵曾、羽曾等變化音名稱
3. **律名**：黃鐘、大呂、太簇等十二律名稱
4. **宮調名稱**：如「文王之宮」「黃鐘之宮」等
5. **各國律制對照**：周、楚、曾、齊、晉等國律名對照
6. **紀年與纪事**：楚惠王五十六年製作鎛鐘的記載

### 樂律學價值

- 是目前所見世界唯一公元前五世紀前的有聲樂律文獻
- 證明了中國古代十二律的實踐開始於周代
- 提供了先秦各國音樂文化交流的直接證據
- 是研究中國古代樂律學體系的第一手資料

## 樂律成就總結

曾侯乙編鐘所代表的先秦樂律體系，取得了五大成就：

1. **確定了中國七聲音階的使用**：銘文中「變宮」一詞的出現，推翻了先秦只有五聲的舊說
2. **證明了十二律的實踐始於周代**：中心音域十二半音齊備，可旋宮轉調
3. **一鐘雙音的聲學奇蹟**：正鼓音與側鼓音相差三度，世界獨有
4. **完整的樂律學文獻**：3755字銘文系統記載了階名、律名、宮調、各國對照
5. **綜合律制的運用**：音律綜合了三分損益律和純律的特點，達到了極高的藝術水準

這些成就充分證明，中華民族在兩千四百多年前就已建立了系統、完整、先進的音樂理論體系，為世界音樂文化的發展做出了偉大貢獻。
