# 曾侯乙編鐘出土紀實

## 發現經過

### 1977年9月 — 意外發現

湖北省隨縣（今隨州市）城郊擂鼓墩，當地駐軍部隊在擴建營房時，發現地下有大量異常規整的褐色泥土。這一不尋常的現象引起了當地文物部門的注意。

隨縣展覽館館長王國貴接到報告後趕往現場，從民工口中得知有人將挖出來的「破銅爛鐵」賣了。他趕緊跑了三次縣城，請來了考古專家。

### 1978年3月 — 實地勘察

以湖北省博物館譚維四為隊長的考古隊開始實地勘察。探工勘探後發現，這是一座比馬王堆一號墓大6倍、比出土越王勾踐劍的望山一號楚墓大8倍的大型墓葬。

墓坑呈不規則多邊形，面積達220多平方米。木槨保存完好，對於古墓而言，這已經算是「豪宅」了。

## 發掘過程

### 1978年5月初 — 正式發掘

經國家文物局批准，由湖北省博物館、武漢大學歷史系考古專業、襄陽地區博物館、隨縣文教局及文化館等單位組成聯合考古發掘隊，隊長為時任湖北省博物館館長、著名考古學家譚維四。

### 5月15日 — 清除填土

墓坑殘留的填土被清除完畢，覆蓋於槨室之上的巨木排列而成的盖板突顯於眼前。

### 5月17日 — 大墓揭開

槨板被打開，眼前的景象令人震驚：墓室內積滿了水，宛如一個面積達兩百餘平方米的「大游泳池」。地面水與地下水混在一起，淤泥將水下器物掩蓋得嚴嚴實實。

譚維四果斷決定先抽乾墓室積水，再開展後續工作。潛水泵的轟鳴打破了古墓的沉靜。

### 5月22日午夜 — 蛟龍出水

水位降至距槨牆頂40-50厘米時，中室隱約出現了三個木架。

5月23日凌晨，水位降到深60厘米處時，人們才發現木架下方懸掛著三組18件青銅鈕鐘。天大亮後，水位繼續下降，「蛟龍出水了！」——木架上的橫梁露出真容：黑漆為底，上面繪有精美的彩繪紋飾。

處於三個不同位置的考古隊員都摸到了水中的鈕鐘，估計有19個。

### 編鐘出水

編鐘的上、中、下層懸掛著大小不同的編鐘，三層編鐘懸掛的方法各不相同：

- **上層小編鐘**：由一根栓釘管住，最簡單、最容易取出
- **中層甬鐘**：以鉤掛方式懸掛，需小心拆卸
- **下層大甬鐘**：體形碩大，最為困難

然而小編鐘的兩面並不一樣，取出時需要特別注意方向。整個編鐘的提取工作是發掘中最複雜、最難操作的環節。

## 歷史意義

曾侯乙編鐘的出土被譽為「改寫世界音樂史的發現」：

1. 證明中國在公元前五世紀已擁有完整的十二律體系
2. 一鐘雙音的聲學奇蹟，領先世界兩千年
3. 3755字銘文是世界上最早的系統性樂律學文獻
4. 青銅鑄造工藝達到當時世界最高水平
