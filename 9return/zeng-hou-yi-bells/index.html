演奏互動 / 01

虛擬編鐘演奏臺

點選編鐘或使用電腦鍵盤 A S D F G H J K L 演奏。每一件鐘都能發出真實的青銅音色，體驗兩千四百年前的宮廷雅樂。
演奏提示

鍵盤對照：A=宮(C) S=商(D) D=角(E) F=清角(F) G=徵(G) H=羽(A) J=變宮(B) K=高宮(C') L=高商(D')
曾侯乙編鐘的音域從 C2 到 d4，橫跨五個半八度。中心音域約三個八度範圍內十二個半音齊備，可以演奏各種調式的樂曲。

演奏互動 / 02

五音互動鍵盤

宮、商、角、徵、羽——中國傳統五聲音階。點選琴鍵聆聽每個音的音色，探索五音與五行、五臟的對應關係。
五聲音階鍵盤
五音 · 五行 · 五臟對應

《黃帝內經》記載五音與五臟相配：宮通脾、商通肺、角通肝、徵通心、羽通腎。 古人以音樂調養身心，不同調式的樂曲對應不同的臟腑調理作用。

演奏互動 / 03

一鐘雙音演示

曾侯乙編鐘最神奇之處：每件鐘都能發出兩個不同的音。敲擊正鼓部與側鼓部，音高相差大三度或小三度。這是合瓦形鐘體結構帶來的獨特聲學奇蹟。

正鼓部振動模式

敲擊鐘口正中的正鼓部，鐘體以橫向振動為主，發出較低的基頻音。 銘文中標註為「宮」「商」等階名。

側鼓部振動模式

敲擊鐘口兩側的側鼓部，激發另一組振動模式，音高比正鼓音高大三度。 銘文標註為「角」「徵曾」等。

音律學問 / 05

三分損益法

中國古代生律法。將一根弦長分為三份，去其一份（損一）或增其一份（益一），依次生成五音。這是世界上最早的音律計算體系之一。
生律公式
宮 = 81 （基準弦長）
81 × 4/3 = 108 → 徵 （益一）
108 × 2/3 = 72 → 商 （損一）
72 × 4/3 = 96 → 羽 （益一）
96 × 2/3 = 64 → 角 （損一）
三分損益 vs 十二平均律
音名 三分損益頻率比 十二平均律頻率比 差異（音分）

三分損益法生成的五音是純粹的自然諧音關係，聽感更和諧純淨； 十二平均律將八度均分為十二份，方便轉調但每個音都略有偏差。 曾侯乙編鐘的音律綜合了三分損益律和純律的特點，是先秦樂律學的巔峰成就。

鐘架與結構

鐘架稱為「筍虡」，由銅木結構構成。橫樑（筍）為長方木，末端有青銅套頭； 立柱（虡）為青銅鑄造的劍士和神獸造型，頂端託舉橫樑。 整套鐘架設計精巧，經歷兩千四百多年仍能穩定懸掛全部鐘體。 鐘體以合瓦形為特徵，這種形狀是實現「一鐘雙音」的關鍵結構。

編鐘探秘 / 08

銘文探索

編鐘及鐘架上共有銘文3755字，是目前所見世界唯一公元前五世紀前的有聲樂律文獻。點選高亮文字檢視詳細解讀。

點選左側高亮文字

銘文內容涉及樂律學的各個方面，包括階名、變化音名、律名、宮調名稱以及各國律制對照。

這些銘文不僅是研究先秦音樂的珍貴資料，更是世界音樂史上最早的系統性樂律學著作。

參觀指南與成就

湖北省博物館位於武漢市東湖之濱，曾侯乙編鐘是其鎮館之寶。完成互動探索可解鎖成就徽章。

參觀資訊

  • 地址：武漢市武昌區東湖路160號
  • 開放時間：週二至週日 9:00-17:00（16:00停止入館）
  • 門票：免費（需提前預約）
  • 編鐘展廳：南館二樓「曾侯乙展」
  • 編鐘演奏：每日定時演出（需單獨購票）

重點看點

  • 曾侯乙編鐘原件（65件全套）
  • 編鐘銘文拓片與樂律解讀
  • 曾侯乙墓出土樂器組（編磬、建鼓、瑟、笙等）
  • 青銅禮器與玉器展覽
  • 楚文化專題展廳

歷史價值

曾侯乙編鐘的出土被譽為「改寫世界音樂史的發現」。它證明瞭中國在公元前五世紀已擁有完整的十二律體系和七聲音階，比西方巴赫時代的十二平均律實踐早了約兩千年。

三次重要演奏

  • 1978年：出土後首次試奏，《東方紅》
  • 1984年：建國35週年，在北京演奏
  • 1997年：香港回歸，譚盾《交響曲1997》

音律理論 / 21

旋宮轉調演示

「旋宮」是指以十二律中的任何一律作為宮音（主音），構成不同的調高。曾侯乙編鐘中心音域十二半音齊備，具備完整的旋宮轉調能力。

旋宮的歷史意義

《戰國策》中記載的「引商刻羽，雜以流徵」，說明當時的音樂已運用複雜的轉調技巧。 曾侯乙編鐘的出土，證明瞭中國在公元前五世紀已具備完整的旋宮轉調能力，比西方類似實踐早了近兩千年。 銘文中記載的「黃鐘之宮」「姑洗之宮」等宮調名稱，正是旋宮理論的直接證據。

音律理論 / 23

五音五行五臟

中國傳統醫學將五音與五行、五臟、五志相配，認為不同調式的音樂可以調理對應的臟腑。《黃帝內經》記載了完整的五音養生理論。
五音配五臟
五音養生
宮音養脾

宮音悠長沉穩，如土般厚重，可調理脾胃，促進消化，緩解焦慮。代表樂曲：《秋湖月夜》

商音養肺

商音高亢悲壯，如金般堅利，可調理肺氣，止咳平喘，增強免疫力。代表樂曲：《陽春白雪》

角音養肝

角音舒展條達，如木般生發，可調理肝氣，疏肝解鬱，緩解易怒。代表樂曲：《胡笳十八拍》

徵音養心

徵音歡明快樂，如火般熱烈，可調理心氣，養心安神，改善失眠。代表樂曲：《喜相逢》

羽音養腎

羽音柔和清越，如水般潤下，可調理腎氣，滋陰補腎，增強記憶力。代表樂曲：《梅花三弄》

「金聲玉振」的含義

孟子評價孔子：「孔子之謂集大成。集大成也者，金聲而玉振之也。」「金聲」指編鐘開頭，「玉振」指編磬收尾。鐘聲渾厚開篇，磬聲清脆收束，象徵孔子思想的完滿與諧和。曾侯乙墓同時出土編鐘與編磬，正是周代「金石之樂」禮制的真實再現。

有趣發現：十絃琴

曾侯乙墓出土的十絃琴是目前發現的唯一一件十絃琴實物，與後世通行的七絃琴不同。琴身長67釐米，由整塊桐木斫成，表面髹黑漆。十弦的設定可能是早期琴制向七絃演變過程中的一種形態。此外還出土了一件五絃琴（又稱「均鍾木」），可能是用來調音的工具，而非演奏樂器。這些發現證明，在戰國早期，古琴的形制尚未完全定型，正處於多樣化的探索階段。

笙：世界上最早使用自由簧的樂器

曾侯乙墓出土了6件笙，是目前發現最早的笙實物。笙由笙鬥、笙管、簧片三部分組成，透過吹氣使簧片振動發聲。值得注意的是，笙是世界上最早使用自由簧（free reed）的樂器，這一原理後來透過絲綢之路傳到西方，啟發了19世紀歐洲手風琴、口琴和簧風琴的發明。可以說，中國的笙是現代所有自由簧樂器的鼻祖。

排簫：「簫韶九成，鳳凰來儀」

曾侯乙墓出土了2件排簫，每件由13根竹管編排而成，長短依次排列，用竹夾固定。排簫在古代又稱「簫」「比竹」，是雅樂中的重要樂器。《尚書》記載「簫韶九成，鳳凰來儀」，描述的就是排簫演奏舜樂《韶》時，連鳳凰都飛來聆聽的盛況。曾侯乙排簫的出土，讓我們得以親眼見到這種在文獻中被反覆讚頌的樂器的真實面貌。

古代樂器 / 55

失傳樂器探秘

在歷史長河中，許多曾經輝煌的古代樂器逐漸失傳，只留下文獻中的記載和考古中的碎片。曾侯乙墓的出土，讓一些失傳千年的樂器重見天日，也讓我們得以窺見那些早已消失的美妙聲音。
失傳樂器圖鑑
重點探秘：篪（chí）

篪是中國古代的橫吹竹管樂器，與笛相似但有本質區別。曾侯乙墓出土了2件篪，是目前發現的唯一實物。篪的特點是：

  • 閉管樂器（兩端封閉），笛是開管
  • 吹孔與指孔在同一平面，笛是垂直
  • 有6個指孔，音色低沉渾厚
  • 演奏時手心朝內，與笛相反
篪的失傳與復原

篪在漢代之後逐漸失傳，後世只知其名不見其形。宋代學者陳暘在《樂書》中描繪的篪與真實形制相差甚遠。直到1978年曾侯乙墓出土，人們才第一次見到篪的真實面貌。

音樂學家對出土篪進行了複製和測試，發現其音色低沉渾厚，有獨特的共鳴，與笛的清脆明亮完全不同。《詩經》中「伯氏吹塤，仲氏吹篪」的記載，描述的就是兄弟二人合奏塤篪的溫馨場景。

失傳樂器的文化意義

每一件失傳樂器的背後，都承載著一段被遺忘的音樂文化。篪的失傳，反映了漢代以後橫吹樂器從閉管向開管（笛）的演變；築的失傳，與魏晉以後琴的興起有關；塤雖然沒有完全失傳，但也從宮廷雅樂的核心淪為邊緣樂器。曾侯乙墓的考古發現，不僅讓這些失傳樂器重見天日，更重要的是，它讓我們認識到：中國古代音樂的豐富性遠遠超出了文獻記載的範圍，還有更多的聲音等待我們去發現和復原。

古代音樂家 / 56

古代音樂家名人堂

從春秋的師曠、伯牙，到魏晉的嵇康，再到唐代的李龜年，中國古代誕生了無數傳奇音樂家。他們不僅技藝超群，更留下了動人的故事和深遠的文化影響。
歷代音樂家名人錄
音樂家的社會地位

在中國古代，音樂家的社會地位經歷了巨大變化。周代，樂官是重要的禮官，「大司樂」是朝廷高階官員，負責全國的音樂教育和禮儀。春秋戰國時期，樂師如師曠不僅是音樂家，更是政治顧問和思想家，「樂與政通」的觀念深入人心。秦漢以後，音樂家逐漸被歸入「伶人」「樂工」之列，社會地位下降，但仍有不少音樂家因其技藝而受到統治者的賞識。唐代是音樂的黃金時代，梨園、教坊匯集了全國最優秀的音樂家，李龜年、賀懷智等名動一時。

古代音樂家 / 57

十大名曲故事

中國古代十大名曲，每一首都背負著一段動人的故事。從高山流水的知音之誼，到廣陵散的臨刑絕唱，這些樂曲不僅是音樂的傑作，更是中華文化的精神縮影。
十大名曲一覽
名曲的傳承與演變

值得注意的是，我們今天聽到的「古代十大名曲」，並非都是原創於古代的樂曲。例如《高山流水》現存版本是近代琴家根據傳說重新創作的；《廣陵散》雖然有明代《神奇秘譜》的傳譜，但與嵇康當年所彈是否完全相同已不可考；《梅花三弄》最早是東晉桓伊的笛曲，後來才被改編為琴曲。這些樂曲在流傳過程中不斷被後世琴家修改、演繹，形成了多種版本。它們的價值不僅在於音樂本身，更在於它們所承載的文化記憶和精神內涵。

古代音樂家 / 58

樂聖師曠傳奇

師曠，字子野，春秋時期晉國樂師，被後世尊為「樂聖」。他是盲人，卻有著超凡的音樂天賦和政治智慧。他的一生充滿傳奇，留下了「清角」「清徵」的神話，以及用琴砸國君的膽識。
師曠生平

傳奇故事
師曠的音樂思想

師曠認為音樂與政治息息相關，「樂與政通」是他的核心思想。他說：「夫樂，以開山川之風也，以耀德之廣也。」音樂不僅是娛樂，更是傳播德行、教化民眾的工具。他反對「新聲」（即當時的流行音樂），認為「新聲」會導致政治混亂。他曾對晉平公說：「公室其將卑乎！君之明兆於衰矣。」透過音樂的變化預測政治的興衰。這種「審樂知政」的觀念，對後世儒家音樂思想產生了深遠影響，《禮記·樂記》中「審聲以知音，審音以知樂，審樂以知政」的論述，正是對師曠思想的繼承和發展。

古代音樂家 / 59

周代樂隊編制

周代建立了中國歷史上最完整的禮樂制度，樂隊的編制有嚴格的等級規定。從天子的「八佾」到諸侯的「六佾」，從編鐘的懸掛數量到樂器的組合，每一處都體現著「禮」的秩序。曾侯乙墓的樂器配置，正是周代諸侯級別樂隊的真實再現。

「八佾舞於庭」的憤怒

周代禮樂制度的核心是「區別等級」，不同等級的貴族使用不同規模的樂隊和舞蹈。魯國大夫季氏在家中使用了天子級別的「八佾」舞蹈（64人），孔子聽說後憤怒地說：「八佾舞於庭，是可忍也，孰不可忍也！」在孔子看來，這種僭越行為不僅是禮儀的破壞，更是政治秩序崩潰的訊號。曾侯乙作為諸侯，使用三面「軒懸」的編鐘編磬，完全符合其等級規定。但他的編鐘數量（65件）和精美程度，甚至超過了當時周天子的規格，這也從一個側面反映了春秋戰國時期「禮崩樂壞」、諸侯僭越的歷史現實。

古代音樂家 / 60

八音分類互動

「八音」是中國古代最早的樂器分類法，根據製作材料將樂器分為金、石、土、革、絲、木、匏、竹八類。這一分類法最早見於《周禮·春官》，距今已有兩千多年歷史，是世界上最早的樂器分類體系之一。

八音與現代分類的對比

中國古代的「八音」分類法（按材料）與現代霍恩博斯特爾-薩克斯分類法（按發聲原理）是兩種不同的分類體系。八音分類簡單直觀，體現了中國古代「格物致知」的思維方式；現代分類法更科學系統，按體鳴、膜鳴、弦鳴、氣鳴四大類劃分。有趣的是，這兩種分類法在某些方面有著驚人的對應：「金」「石」對應體鳴樂器，「革」對應膜鳴，「絲」對應弦鳴，「匏」「竹」「土」對應氣鳴。這說明無論東西方，人們對樂器的認識都有著共通的邏輯。
