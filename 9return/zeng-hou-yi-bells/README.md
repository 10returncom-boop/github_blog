# 曾侯乙編鐘 — 千古絕響 動態網站

## 項目簡介

本項目是一個以曾侯乙編鐘為主題的互動式動態網站，透過 Web Audio API 合成青銅鐘音色，結合五音音律、編鐘結構、銘文探索等互動功能，再現兩千四百年前的宮廷雅樂。

## 文件結構

```
曾侯乙編鐘/
├── index.html          # 主網站（單文件自包含）
├── README.md           # 項目說明（本文件）
└── docs/               # 配套資料文檔
    ├── 出土紀實.md      # 1978年發掘過程詳細記錄
    ├── 鑄造工藝.md      # 青銅合金配比與陶範鑄造技術
    ├── 聲學原理.md      # 合瓦形結構與一鐘雙音原理
    ├── 樂律體系.md      # 五音十二律與三分損益法
    └── 曾侯乙生平.md    # 墓主人與戰國曾國歷史背景
```

## 十大功能

| 編號 | 功能 | 說明 |
|------|------|------|
| 01 | 虛擬編鐘演奏台 | 點擊或鍵盤演奏，Web Audio 合成青銅音色 |
| 02 | 五音交互鍵盤 | 宮商角徵羽五聲音階，對應五行五臟 |
| 03 | 一鐘雙音演示 | 正鼓音與側鼓音對比，相差大三度 |
| 04 | 音域頻譜可視化 | Canvas 實時頻譜，五個半八度音域展示 |
| 05 | 三分損益法 | 五音生律公式推演，與十二平均律對比 |
| 06 | 自動演奏樂曲 | 內建四首古曲自動播放 |
| 07 | 編鐘結構展示 | 三層八組65件鐘分層展示 |
| 08 | 銘文探索 | 3755字銘文竹簡式展示與解讀 |
| 09 | 音律知識問答 | 8道互動答題與解析 |
| 10 | 參觀指南與成就 | 博物館信息與10枚探索成就 |

## 技術特點

- **單文件架構**：原生 HTML/CSS/JS，無構建工具，無外部依賴
- **Web Audio 音色合成**：非諧波泛音比例（1:2.76:5.4:8.93）+ 指數衰減包絡 + 敲擊噪聲
- **青銅主題視覺**：深青黑底 + 銅綠鏽 + 硃紅 + 金銅色
- **響應式設計**：適配桌面與移動端
- **成就系統**：localStorage 持久化探索進度

## 使用方式

直接以瀏覽器打開 `index.html` 即可。首次點擊鐘體時瀏覽器會啟用音頻（瀏覽器自動播放策略要求）。
