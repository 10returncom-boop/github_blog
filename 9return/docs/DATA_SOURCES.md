### 2. data.gov.tw 國家發展委員會資料開放平台

- 網址：https://data.gov.tw
- 新竹市公寓大廈報備資料集：透過平台 API 下載
- 授權：政府開放資料授權條款

### 3. 內政部建築管理資訊系統

- 建照/使用執照統計資料
- 第一次登記（完工登記）棟數
- 用於總覽指標與縣市別統計交叉驗證

### 4. 實價登錄資料

- 內政部不動產成交案件實際資訊申報系統
- 用於個案建案連結（未直接儲存於本平台）

## 資料品質說明

### 已知限制

1. **戶數欄位**：新竹市開放資料未提供戶數，故總戶數統計不含新竹市
2. **地址欄位**：部分早期批次地址不完整，已標記於資料來源欄
3. **重複資料**：多批次合併可能存在重複，已依使照序號去重
4. **建物型態**：為自動分類結果（依名稱關鍵字），可能有誤判
5. **重劃區標記**：依名稱/地址關鍵字比對，僅供參考

### 資料更新頻率

- 政府開放資料：不定期更新（各縣市自行決定）
- 本平台：手動彙整，有新資料時隨時更新
- 建議：每季度檢查各縣市開放資料平台是否有新批次
