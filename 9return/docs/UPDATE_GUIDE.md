# 資料更新與新增縣市指南

## 概述

本平台採用「資料驅動」架構，新增或更新縣市資料**不需改動網站程式碼**，只需：

1. 準備符合格式的 CSV 資料
2. 放入 `data/raw/` 目錄
3. 執行建置腳本
4. 提交至 GitHub

---

## 一、更新既有縣市資料

### 步驟 1：取得新資料

從各縣市政府開放資料平台或 data.gov.tw 下載最新公寓大廈報備資料。

### 步驟 2：準備 CSV 格式

CSV 必須包含以下欄位（欄位名稱需完全一致）：

```csv
縣市,使照序號,公寓大廈名稱,行政區,地址,戶數,管理組織型態,建物型態,重劃區標記,資料來源
```

**欄位說明：**

| 欄位 | 必填 | 說明 |
|------|------|------|
| 縣市 | 是 | 繁體中文，如「臺中市」「新竹市」 |
| 使照序號 | 是 | 使用執照序號，作為去重依據 |
| 公寓大廈名稱 | 是 | 建案/社區名稱 |
| 行政區 | 是 | 鄉鎮市區，如「西屯區」「東區」 |
| 地址 | 是 | 完整地址（盡量包含門牌號碼） |
| 戶數 | 否 | 總戶數，無資料則留空 |
| 管理組織型態 | 否 | 管理委員會/區分所有權人會議/其他 |
| 建物型態 | 否 | 大樓/華廈/公寓/社區/其他（留空則自動分類） |
| 重劃區標記 | 否 | 重劃區名稱（留空則自動比對） |
| 資料來源 | 是 | 來源標記，如「data.gov.tw 臺中市開放資料(2026-09)」 |

### 步驟 3：合併至主資料檔

將新資料與 `data/raw/全台公寓大廈報備資料彙整_v2.1.csv` 合併，依「使照序號」去重（新資料覆蓋舊資料）。

```bash
# 使用 Python 合併範例
python -c "
import pandas as pd
old = pd.read_csv('data/raw/全台公寓大廈報備資料彙整_v2.1.csv', dtype=str)
new = pd.read_csv('data/raw/新資料.csv', dtype=str)
merged = pd.concat([old, new]).drop_duplicates(subset='使照序號', keep='last')
merged.to_csv('data/raw/全台公寓大廈報備資料彙整_v2.2.csv', index=False, encoding='utf-8-sig')
print(f'合併完成：{len(merged)} 筆')
"
```

### 步驟 4：更新建置腳本的資料檔路徑

編輯 `scripts/build_dashboard.py`，將輸入檔路徑改為新版本：

```python
INPUT_CSV = 'data/raw/全台公寓大廈報備資料彙整_v2.2.csv'
```

### 步驟 5：執行建置

```bash
python scripts/build_dashboard.py
```

輸出：
- `data/overview.json`
- `data/county_stats.json`
- `data/district_stats.json`
- `data/case_db.json`
- `index.html`
- `counties/*.html`（每個有資料的縣市各一頁）

### 步驟 6：本地預覽驗證

```bash
python -m http.server 8080
# 瀏覽器開啟 http://localhost:8080
```

確認：
- [ ] 總覽指標數字正確
- [ ] 縣市別表格包含更新的縣市
- [ ] 個案建案明細庫可搜尋到新資料
- [ ] 縣市子頁連結正常

### 步驟 7：提交至 GitHub

```bash
git add .
git commit -m "更新資料：臺中市 2026-09 批次，新增 XXX 筆"
git push origin main
```

GitHub Pages 會自動重新部署，約 1-2 分鐘後生效。

## 二、新增縣市（目前待補 14 縣市）

### 適用情境

- 宜蘭縣、新竹縣、苗栗縣、南投縣、雲林縣、嘉義縣、屏東縣、臺東縣、花蓮縣、澎湖縣、金門縣、連江縣、基隆市、高雄市

### 步驟

1. **取得該縣市公寓大廈報備開放資料**
   - 優先查詢 data.gov.tw
   - 其次查詢該縣市政府官網的開放資料區
   - 若伺服器異常（如宜蘭縣），記錄並等待恢復

2. **轉換為標準 CSV 格式**（欄位同上）

3. **合併至主資料檔**（同上）

4. **執行建置腳本**
   - 腳本會自動偵測新縣市並產生對應的 `counties/xxx.html`
   - 首頁縣市別表格會自動加入新縣市

5. **更新 README.md**
   - 將該縣市從「待補縣市」移至「已涵蓋縣市」
   - 更新統計數字（筆數、行政區數等）

6. **驗證並提交**

### 注意事項

- 縣市名稱必須使用**繁體中文標準名稱**（如「臺北市」非「台北市」）
- 若該縣市資料無戶數欄位，總戶數統計不會包含該縣市（屬正常現象）
- 新增縣市後，總覽的「已涵蓋縣市」數字會自動更新

## 三、常見問題

### Q: 建置腳本執行失敗怎麼辦？

A: 檢查：
1. CSV 編碼是否為 UTF-8（建議 UTF-8 with BOM）
2. 欄位名稱是否完全一致
3. 是否有缺少必填欄位
4. Python 版本是否為 3.8+

### Q: 新增縣市後沒有出現在網站上？

A: 檢查：
1. CSV 中「縣市」欄位是否有值
2. 是否重新執行 `build_dashboard.py`
3. `counties/` 目錄下是否有對應的 HTML 檔
4. 瀏覽器是否快取（Ctrl+F5 強制重新整理）

### Q: 如何還原到前一版本？

A: 使用 Git：
```bash
git log --oneline
git checkout <commit-hash> -- data/raw/
python scripts/build_dashboard.py
```

### Q: 資料有錯誤如何回報？

A: 在 GitHub 發 Issue，標註：
- 錯誤的使照序號或建案名稱
- 正確的資訊
- 資料來源（如有）
