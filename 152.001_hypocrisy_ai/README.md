## 一、本站主題

AI 的討好是程式、人類的虛偽是人生。本站用 **30 個真實心理學經典研究**，以大白話、幽默的方式拆解「人類為什麼這麼會演」，每篇文章末尾皆附：

1. 學者、年份、研究名稱、期刊/出版社；
2. 「AI 對照組」段落，把人類行為與 AI 無自我、無利益動機的順從行為對照。

## 四、技術規格

- **單檔自包含**：`index.html` 一個檔案，CSS/JS 全部內嵌。
- **字型**：Noto Serif TC + Noto Sans TC（經 miaoda.feishu.cn 鏡像）。
- **主題**：CSS 變數 + `data-theme` 三態（day / night / auto），跟隨系統用 `prefers-color-scheme`。
- **狀態持久化**：localStorage 存 theme、lang、fontScale、favs、notes、recent。
- **無外部 JS 庫**：純原生 JS，不依賴 React / Vue / jQuery。
- **無外部圖片**：favicon 用內聯 SVG，圖片未嵌入以保持單檔輕量。
